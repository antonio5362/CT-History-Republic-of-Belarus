# История Беларуси · ЦТ — Android-приложение

WebView-обёртка над вашим HTML (`app/src/main/assets/index.html`).

## Как получить APK (без установки Android Studio)
1. Создайте репозиторий на github.com (можно приватный) и загрузите в него ВСЁ содержимое этой папки
   (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** → **Build APK** → дождитесь зелёной галочки (3–5 мин).
   Если сборка не запустилась сама — нажмите **Run workflow**.
3. Откройте выполненный запуск → внизу **Artifacts → CTHistory-apk** → скачайте zip, внутри `app-release.apk`.
4. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

## Через Android Studio
Открыть папку как проект → Build → Build APK(s).

## Обновить содержимое
Замените `app/src/main/assets/index.html` и пересоберите. Для нового релиза поднимите `versionCode` в `app/build.gradle`.

Прогресс хранится в localStorage внутри приложения; при удалении приложения он сбрасывается.
